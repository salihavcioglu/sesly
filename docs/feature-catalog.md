# Features and engines

Engine availability depends on installed models, hardware, and configured providers.

- **Voice Cloning**
- **Voice Design**
- **Video Dubbing**
- **Dictation Widget**
- **Vocal Isolation**
- **Speaker Diarization**
- **Batch Queue**
- **MCP Server**
- **AI Watermark**
- **Local-first**
- **GPU Auto-Detect**
- **Remote Model Downloads**
- **Extensible**
